# Changelog

## Unreleased

- NStack cards keep names and abbreviated identities readable on narrow screens, with secondary actions in an accessible menu. Long names have bounded lines; headers, workspace rows and connection details accommodate larger text.

- NStack connections keep editable display names and hide URLs and full identities until connection details are opened. Changing an address requires the same verified identity and preserves saved workspaces, bookmarks and backup selections. Service catalogues are discovered with a bounded deadline and disclosed only after origin consent.
- Command-Right switches browser tabs and Command-Left opens the browser menu while preserving native and embedded editor shortcuts, composing input, and modal focus.
- TestFlight supports explicit reviewed cancellation of proved never-uploaded exports from competing release roots. Native logs, signed artifacts, finished claims and stopped owners must match; original records remain intact, cancelled numbers remain reserved, and every future Apple history check revalidates the evidence.
- Mobile Tabs overview now uses the active new-tab wallpaper, including the bundled default after resetting a custom background. The wallpaper fills the screen behind the header and tab cards; opaque control and card surfaces retain readable text. Tab selection, closing, adding and dismissal retain their existing behavior.
